# Legacy images

Drop the images copied from the previous glazebrookecoffee.com website here,
exactly as they are (original filenames are fine).

## How to upload (GitHub website)

1. Make sure the branch selector (top left of the file list) shows **legacy-images**.
2. Open this `legacy-images` folder.
3. Click **Add file → Upload files** and drag the images in (up to 100 per upload).
4. Choose **Commit directly to the `legacy-images` branch** and click **Commit changes**.

Text copied from the old site (About page, contact details, product names and
prices) can go here too, as `.txt`, `.md` or `.docx` files.

## What happens next

Each image is reviewed, matched to a photo slot on the new sites (see
`packages/brand/photos/README.md`), renamed, given accurate alt text, and
recorded in `IMAGE-ASSETS.md` with its source. This folder itself is not
published on either website.

Only upload images the estate owns or has permission to reuse.
